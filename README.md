# 🎵 Rast Music Shop

Онлайн-магазин музыкальных инструментов и студийного оборудования (**[rastmusicshop.com](https://rastmusicshop.com/)**).

![Rast Music Shop](public/images/hero.png)

---

## 🚀 О проекте

**Rast Music Shop** — платформа для продажи и обслуживания музыкальных инструментов:
- **Широкий ассортимент:** Гитары, клавишные, смычковые, ударные, духовые, звуковое оборудование, национальные азербайджанские инструменты и аксессуары.
- **Услуги ремонта и реставрации:** Интерактивный интерактивный слайдер сравнения состояния инструментов «До» и «После» реставрации.
- **Кредитный калькулятор рассрочки:** Интегрированный расчет ежемесячных платежей (Birkart, Tamkart, ABB Kredit, Ferrum DTI от 2 до 18 месяцев).
- **Поиск и фильтрация:** Поиск с автозаполнением в реальном времени и фильтрация по категориям/ценам.
- **Корзина и оформление:** Локальное сохранение корзины (`localStorage`), быстрый подсчет стоимости и удобная форма заказа.
- **Мультиязычность:** Поддержка азербайджанского (AZ), русского (RU) и английского (EN) языков.
- **Адаптивный дизайн:** Оптимизировано для компьютеров, планшетов и смартфонов.

## 🛠 Технологический стек

- **Frontend:** React 18 / 19, React Router v6
- **Сборщик:** Vite 6
- **Стилизация:** CSS3 (Variables, Glassmorphism), Tailwind CSS
- **Backend & Database:** [Supabase](https://supabase.com/) (PostgreSQL, Auth, Storage)

## 💻 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/umidbabayeff/rastmusicshop.git
cd rastmusicshop
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корневой папке:
```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

### 4. Запуск в режиме разработки
```bash
npm run dev
```
Сайт будет доступен по адресу: `http://localhost:3000/`

### 5. Продакшн-сборка
```bash
npm run build
```
Готовая сборка будет находиться в директории `dist/`.
